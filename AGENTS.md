# Missing Alerts Project Rules

- This project is Missing Alerts, not Search Command HQ.
- FindTrax is a Missing Alerts app/product, not a separate website.
- Never invent real missing-person cases for production pages.
- Public pages must use public-safe mapped case data only.
- Found-safe, located and closed cases must hide identifying photos by default.
- Active public listings include only active, urgent and long-term cases.
- Boosted Appeals must not include private, draft, review, found-safe, located, closed or archived cases.
- Keep scanner imports source-driven and source-attributed.
- Run `npm test` and `npm run build` before finishing.
